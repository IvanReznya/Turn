# Предикат поворота

## Запуск

Откройте CMakeLists.txt из этой папки в Qt Creator, выберите Desktop Qt Kit и нажмите Run.

Сборка в терминале:

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH="/путь/к/Qt/ваш_комплект"
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```


## Управление

Два клика задают A и B, третий — P. Результат 1 / -1 / 0 и цвет P показывают сторону от направленного AB. Точки перетаскиваются. Галочка включает онлайн-пересчёт, кнопка выполняет ручной расчёт.

## Ограничения

Исходный предикат использует double. Для почти коллинеарных чисел произвольной длины предназначено отдельное задание 03_exact_turn.
